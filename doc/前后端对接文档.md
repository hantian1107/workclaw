## 通信架构概述

### 架构图

```
┌─────────────────────────────────────────────────────────────────┐
│                         渲染进程（前端）                          │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │ React 应用 (src/renderer/App.tsx)                        │ │
│  │ - 对话界面                                                 │ │
│  │ - 工作空间管理                                             │ │
│  │ - 消息展示                                                 │ │
│  └───────────────────────────────────────────────────────────┘ │
│                            ↕ window.electron                   │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │ Preload 脚本 (src/main/preload.ts)                        │ │
│  │ - contextBridge 安全暴露 API                                │ │
│  │ - ipcRenderer 消息转发                                      │ │
│  └───────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                              ↕ IPC 通信
┌─────────────────────────────────────────────────────────────────┐
│                         主进程（后端）                           │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │ IPC 通道 (src/channels/ipc/index.ts)                      │ │
│  │ - ipcMain 消息监听                                         │ │
│  │ - 消息路由                                                 │ │
│  └───────────────────────────────────────────────────────────┘ │
│                            ↕                                   │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │ Application (src/main/index.ts)                            │ │
│  │ - 消息处理                                                 │ │
│  │ - Agent 调用                                               │ │
│  │ - 工作空间管理                                             │ │
│  └───────────────────────────────────────────────────────────┘ │
│                            ↕                                   │
│  ┌─────────────────┐  ┌─────────────────┐  ┌───────────────┐  │
│  │ Agent (AI 代理) │  │ WorkspaceManager│  │ Core (核心)  │  │
│  └─────────────────┘  └─────────────────┘  └───────────────┘  │
└─────────────────────────────────────────────────────────────────┘
```

### 通信方式

Workclaw 使用 Electron 的 **IPC (Inter-Process Communication)** 机制进行前后端通信：

- **单向通信**：`ipcRenderer.send()` → `ipcMain.on()`
- **双向通信**：`ipcRenderer.invoke()` → `ipcMain.handle()`（Promise 方式）
- **主进程推送**：`webContents.send()` → `ipcRenderer.on()`

### 安全机制

- **contextIsolation**: 启用上下文隔离，确保预加载脚本和渲染进程隔离
- **nodeIntegration**: 禁用 Node.js 集成，防止渲染进程直接访问系统资源
- **sandbox**: 启用沙箱模式，进一步限制渲染进程权限
- **contextBridge**: 仅暴露必要的 API 给渲染进程

## 消息协议规范

### 用户消息 (UserMessage)

前端发送给后端的消息格式：

```typescript
interface UserMessage {
  id: string;                    // 消息唯一标识
  content: string;               // 消息内容
  userId: string;                // 用户 ID
  timestamp: string;             // 时间戳 (ISO 8601)
  metadata?: Record<string, any>; // 可选元数据
}
```

### 代理消息 (AgentMessage)

后端发送给前端的消息格式：

```typescript
interface AgentMessage {
  id: string;                    // 消息唯一标识
  content: string;               // 消息内容
  timestamp: string;             // 时间戳 (ISO 8601)
  metadata?: Record<string, any>; // 可选元数据
}
```

### 示例

**前端发送消息：**
```json
{
  "id": "msg-1710240000000",
  "content": "你好，请帮我写一个 Python 脚本",
  "userId": "local-user",
  "timestamp": "2026-03-12T10:00:00.000Z",
  "channelId": "ipc-channel"
}
```

**后端回复消息：**
```json
{
  "id": "msg-1710240001000",
  "content": "好的，这是一个简单的 Python 脚本示例：\n\n```python\nprint('Hello, World!')\n```",
  "timestamp": "2026-03-12T10:00:01.000Z"
}
```

### 对话数据类型

#### Conversation（对话）

```typescript
interface Conversation {
  id: string;                    // 对话唯一标识
  title: string;                 // 对话标题
  workspaceId?: string;          // 所属工作空间 ID（可选）
  messages: Message[];           // 对话消息列表
  createdAt: string;             // 创建时间
  updatedAt: string;             // 最后更新时间
}
```

#### Message（单条消息）

```typescript
interface Message {
  id?: string;                   // 消息 ID（可选）
  role: 'user' | 'assistant' | 'system';  // 消息角色
  content: string;               // 消息内容
  timestamp: string;             // 时间戳
}
```

#### ConversationInfo（对话摘要）

用于对话列表展示的简化信息：

```typescript
interface ConversationInfo {
  id: string;                    // 对话 ID
  title: string;                 // 对话标题
  lastMessage: string;           // 最后一条消息预览
  lastMessageTime: string;       // 最后一条消息时间
  messageCount: number;          // 消息总数
  workspaceId?: string;          // 所属工作空间 ID
  createdAt: string;             // 创建时间
}
```

## API 接口文档

### 1. 消息通信 API

#### 1.1 发送消息

**方法名**: `window.electron.sendMessage()`

**描述**: 向前端发送用户消息到主进程

**参数**:
```typescript
message: {
  id?: string;           // 可选，消息 ID
  content: string;       // 必填，消息内容
  userId?: string;       // 可选，用户 ID
  timestamp?: string;    // 可选，时间戳
  channelId?: string;    // 可选，通道 ID
}
```

**返回值**: `void`

**示例**:
```typescript
window.electron.sendMessage({
  content: "你好，请帮我分析这段代码",
  userId: "user-123"
});
```

---

#### 1.2 监听消息

**方法名**: `window.electron.onMessage()`

**描述**: 监听来自主进程的消息

**参数**:
```typescript
callback: (message: AgentMessage) => void
```

**返回值**: `void`

**示例**:
```typescript
window.electron.onMessage((message) => {
  console.log('收到 AI 回复:', message.content);
  // 更新 UI 显示消息
});
```

## 工作空间接口

### 2.1 创建工作空间

**方法名**: `window.electron.workspace.create()`

**描述**: 创建一个新的工作空间

**参数**:
```typescript
name: string;           // 工作空间名称
description: string;    // 工作空间描述
```

**返回值**: `Promise<Workspace>`

**Workspace 类型**:
```typescript
interface Workspace {
  id: string;
  name: string;
  description: string;
  resources: Resource[];
  createdAt: string;
  updatedAt: string;
}

interface Resource {
  path: string;
  type: 'file' | 'directory' | 'app';
  permissions: 'read' | 'write' | 'execute' | 'all';
}
```

**示例**:
```typescript
const workspace = await window.electron.workspace.create(
  "我的项目",
  "这是我的开发工作空间"
);
console.log('创建成功:', workspace);
```

---

### 2.2 获取工作空间列表

**方法名**: `window.electron.workspace.list()`

**描述**: 获取所有工作空间列表

**参数**: 无

**返回值**: `Promise<Workspace[]>`

**示例**:
```typescript
const workspaces = await window.electron.workspace.list();
console.log('工作空间列表:', workspaces);
```

---

### 2.3 切换工作空间

**方法名**: `window.electron.workspace.switch()`

**描述**: 切换到指定的工作空间

**参数**:
```typescript
id: string;  // 工作空间 ID
```

**返回值**: `Promise<boolean>`

**示例**:
```typescript
const success = await window.electron.workspace.switch("workspace-1234567890");
if (success) {
  console.log('切换成功');
}
```

---

### 2.4 添加资源到工作空间

**方法名**: `window.electron.workspace.addResource()`

**描述**: 向指定工作空间添加资源

**参数**:
```typescript
workspaceId: string;  // 工作空间 ID
resource: Resource;   // 资源对象
```

**返回值**: `Promise<boolean>`

**示例**:
```typescript
const success = await window.electron.workspace.addResource(
  "workspace-1234567890",
  {
    path: "/Users/username/projects",
    type: "directory",
    permissions: "all"
  }
);
```

## 前端使用示例

### 完整对话流程示例

```typescript
import React, { useState, useEffect } from 'react';

function ChatComponent() {
  const [messages, setMessages] = useState<any[]>([]);
  const [inputText, setInputText] = useState('');
  const [isLoading, setIsLoading] = useState(false);

  // 组件挂载时监听主进程消息
  useEffect(() => {
    if (window.electron) {
      window.electron.onMessage((agentMessage) => {
        // 收到 AI 回复，添加到消息列表
        setMessages(prev => [...prev, {
          id: agentMessage.id,
          content: agentMessage.content,
          role: 'assistant',
          timestamp: agentMessage.timestamp
        }]);
        setIsLoading(false);
      });
    }
  }, []);

  // 发送消息
  const handleSend = async () => {
    if (!inputText.trim()) return;

    // 构造用户消息
    const userMessage = {
      id: `msg-${Date.now()}`,
      content: inputText,
      role: 'user',
      timestamp: new Date().toISOString()
    };

    // 添加到本地消息列表
    setMessages(prev => [...prev, userMessage]);
    setInputText('');
    setIsLoading(true);

    // 发送到主进程
    if (window.electron) {
      window.electron.sendMessage({
        id: userMessage.id,
        content: userMessage.content,
        userId: 'local-user',
        timestamp: userMessage.timestamp,
        channelId: 'ipc-channel'
      });
    }
  };

  return (
    <div>
      <div className="messages">
        {messages.map(msg => (
          <div key={msg.id} className={`message ${msg.role}`}>
            {msg.content}
          </div>
        ))}
        {isLoading && <div className="loading">AI 正在思考...</div>}
      </div>
      
      <input
        value={inputText}
        onChange={(e) => setInputText(e.target.value)}
        onKeyPress={(e) => e.key === 'Enter' && handleSend()}
        placeholder="输入消息..."
      />
      <button onClick={handleSend}>发送</button>
    </div>
  );
}
```

### 工作空间管理示例

```typescript
import React, { useState, useEffect } from 'react';

function WorkspaceManager() {
  const [workspaces, setWorkspaces] = useState<any[]>([]);
  const [currentWorkspace, setCurrentWorkspace] = useState<string | null>(null);

  // 加载工作空间列表
  const loadWorkspaces = async () => {
    if (window.electron) {
      const list = await window.electron.workspace.list();
      setWorkspaces(list);
    }
  };

  // 创建新工作空间
  const handleCreateWorkspace = async () => {
    const name = prompt('请输入工作空间名称:');
    const description = prompt('请输入工作空间描述:');
    
    if (name && window.electron) {
      const newWorkspace = await window.electron.workspace.create(name, description);
      setWorkspaces(prev => [...prev, newWorkspace]);
    }
  };

  // 切换工作空间
  const handleSwitchWorkspace = async (id: string) => {
    if (window.electron) {
      const success = await window.electron.workspace.switch(id);
      if (success) {
        setCurrentWorkspace(id);
      }
    }
  };

  useEffect(() => {
    loadWorkspaces();
  }, []);

  return (
    <div>
      <button onClick={handleCreateWorkspace}>+ 新建工作空间</button>
      
      <div className="workspace-list">
        {workspaces.map(workspace => (
          <div
            key={workspace.id}
            className={`workspace-item ${currentWorkspace === workspace.id ? 'active' : ''}`}
            onClick={() => handleSwitchWorkspace(workspace.id)}
          >
            <h3>{workspace.name}</h3>
            <p>{workspace.description}</p>
            <small>创建于: {new Date(workspace.createdAt).toLocaleDateString()}</small>
          </div>
        ))}
      </div>
    </div>
  );
}
```

### 对话管理完整示例

```typescript
import React, { useState, useEffect } from 'react';

function ConversationManager() {
  const [conversations, setConversations] = useState<any[]>([]);
  const [currentConversationId, setCurrentConversationId] = useState<string | null>(null);
  const [currentConversation, setCurrentConversation] = useState<any>(null);
  const [isLoading, setIsLoading] = useState(false);

  // 加载对话列表
  const loadConversations = async (workspaceId?: string) => {
    if (window.electron) {
      const list = await window.electron.conversation.list(workspaceId);
      setConversations(list);
    }
  };

  // 创建新对话
  const handleCreateConversation = async () => {
    const title = prompt('请输入对话标题:') || '新对话';
    const workspaceId = null; // 可以从当前选中的工作空间获取

    if (window.electron) {
      const newConversation = await window.electron.conversation.create(title, workspaceId);
      setConversations(prev => [...prev, {
        id: newConversation.id,
        title: newConversation.title,
        lastMessage: '',
        lastMessageTime: newConversation.createdAt,
        messageCount: 0,
        createdAt: newConversation.createdAt
      }]);
      // 自动切换到新对话
      handleSelectConversation(newConversation.id);
    }
  };

  // 选择对话
  const handleSelectConversation = async (id: string) => {
    setCurrentConversationId(id);
    setIsLoading(true);

    if (window.electron) {
      const conversation = await window.electron.conversation.get(id);
      setCurrentConversation(conversation);
    }

    setIsLoading(false);
  };

  // 删除对话
  const handleDeleteConversation = async (id: string, e: React.MouseEvent) => {
    e.stopPropagation(); // 防止触发选择对话

    if (!confirm('确定要删除这个对话吗？')) return;

    if (window.electron) {
      const success = await window.electron.conversation.delete(id);
      if (success) {
        setConversations(prev => prev.filter(c => c.id !== id));
        // 如果删除的是当前选中的对话，清空当前对话
        if (currentConversationId === id) {
          setCurrentConversationId(null);
          setCurrentConversation(null);
        }
      }
    }
  };

  // 更新对话标题
  const handleUpdateTitle = async (id: string) => {
    const conversation = conversations.find(c => c.id === id);
    if (!conversation) return;

    const newTitle = prompt('请输入新标题:', conversation.title);
    if (!newTitle || !window.electron) return;

    const success = await window.electron.conversation.updateTitle(id, newTitle);
    if (success) {
      setConversations(prev => prev.map(c => 
        c.id === id ? { ...c, title: newTitle } : c
      ));
      if (currentConversation && currentConversation.id === id) {
        setCurrentConversation(prev => prev ? { ...prev, title: newTitle } : null);
      }
    }
  };

  // 清空对话消息
  const handleClearConversation = async (id: string, e: React.MouseEvent) => {
    e.stopPropagation();

    if (!confirm('确定要清空这个对话的所有消息吗？')) return;

    if (window.electron) {
      const success = await window.electron.conversation.clear(id);
      if (success) {
        // 重新加载对话详情
        if (currentConversationId === id) {
          handleSelectConversation(id);
        }
        // 更新对话列表中的消息计数
        setConversations(prev => prev.map(c =>
          c.id === id ? { ...c, messageCount: 0, lastMessage: '' } : c
        ));
      }
    }
  };

  useEffect(() => {
    loadConversations();
  }, []);

  return (
    <div className="conversation-manager">
      {/* 对话列表 */}
      <div className="conversation-list">
        <div className="list-header">
          <h2>对话</h2>
          <button onClick={handleCreateConversation}>+ 新建对话</button>
        </div>
        
        {conversations.map(conversation => (
          <div
            key={conversation.id}
            className={`conversation-item ${currentConversationId === conversation.id ? 'active' : ''}`}
            onClick={() => handleSelectConversation(conversation.id)}
          >
            <div className="conversation-info">
              <div className="conversation-title">{conversation.title}</div>
              <div className="conversation-preview">{conversation.lastMessage || '暂无消息'}</div>
              <div className="conversation-meta">
                <span>{conversation.messageCount} 条消息</span>
                <span>{new Date(conversation.lastMessageTime || conversation.createdAt).toLocaleTimeString()}</span>
              </div>
            </div>
            <div className="conversation-actions">
              <button 
                onClick={(e) => handleUpdateTitle(conversation.id, e)}
                title="重命名"
              >
                ✏️
              </button>
              <button 
                onClick={(e) => handleClearConversation(conversation.id, e)}
                title="清空消息"
              >
                🗑️
              </button>
              <button 
                onClick={(e) => handleDeleteConversation(conversation.id, e)}
                title="删除对话"
              >
                🗑️
              </button>
            </div>
          </div>
        ))}
      </div>

      {/* 对话详情 */}
      {currentConversation && (
        <div className="conversation-detail">
          <div className="detail-header">
            <h3>{currentConversation.title}</h3>
            <small>创建于: {new Date(currentConversation.createdAt).toLocaleString()}</small>
          </div>
          
          <div className="messages">
            {currentConversation.messages.map((msg: any, index: number) => (
              <div key={index} className={`message ${msg.role}`}>
                <div className="message-content">{msg.content}</div>
                <div className="message-time">
                  {new Date(msg.timestamp).toLocaleTimeString()}
                </div>
              </div>
            ))}
            {currentConversation.messages.length === 0 && (
              <div className="empty-state">暂无消息，开始聊天吧！</div>
            )}
          </div>
        </div>
      )}
    </div>
  );
}
```

## 注意事项

### 1. TypeScript 类型支持

项目已在 `preload.ts` 中声明了全局类型，在 TypeScript 中可以直接使用，无需额外类型定义：

```typescript
// 直接使用，会有类型提示
window.electron.sendMessage({ content: "hello" });
```

### 2. 错误处理

建议在调用 API 时添加错误处理：

```typescript
try {
  const workspace = await window.electron.workspace.create("名称", "描述");
} catch (error) {
  console.error('创建工作空间失败:', error);
  // 显示错误提示给用户
}
```

### 3. 开发环境 vs 生产环境

- **开发环境**: 窗口会自动打开 DevTools
- **生产环境**: DevTools 不会打开，加载打包后的静态文件

### 4. 消息队列

由于 AI 处理可能需要较长时间，建议：
- 发送消息后显示加载状态
- 避免用户重复发送相同消息
- 实现消息取消功能（可选）

### 5. 工作空间资源权限

添加资源时请确保：
- 路径存在且可访问
- 权限设置合理（避免过度授权）
- 敏感目录需要用户确认

### 6. 对话数据持久化

当前对话数据存储在内存中，重启应用后会丢失。如需持久化：
- 建议使用本地文件存储或数据库
- 在创建/更新/删除对话时同步保存到磁盘
- 应用启动时从磁盘加载对话数据

### 7. 对话标题自动生成

可以根据第一条用户消息自动生成对话标题：
- 使用 LLM 提取消息主题
- 或取消息的前 20-30 个字符作为标题
- 允许用户后续手动修改标题

### 8. 删除操作确认

删除对话是不可逆操作，建议：
- 显示确认对话框
- 提供撤销功能（在短时间内）
- 删除前备份对话数据
