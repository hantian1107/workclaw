## ADDED Requirements

### Requirement: Code Reading and Analysis
The system SHALL provide a skill to read and analyze code files.

#### Scenario: Read Source Code
- **WHEN** user asks to explain a specific file
- **THEN** the coding skill reads the file content and provides an explanation

### Requirement: Code Modification
The system SHALL provide a skill to modify code files safely.

#### Scenario: Refactor Code
- **WHEN** user asks to refactor a function
- **THEN** the coding skill reads the file, generates the refactored code, and writes it back

### Requirement: Code Generation
The system SHALL provide a skill to generate new code files.

#### Scenario: Generate Boilerplate
- **WHEN** user asks to create a new component
- **THEN** the coding skill generates the file with appropriate boilerplate code
