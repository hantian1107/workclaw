## ADDED Requirements

### Requirement: Document Generation
The system SHALL provide a skill to generate structured documentation.

#### Scenario: Generate README
- **WHEN** user asks to write a README for the project
- **THEN** the writer skill analyzes the project structure and generates a comprehensive README.md

### Requirement: Content Summarization
The system SHALL provide a skill to summarize content.

#### Scenario: Summarize Article
- **WHEN** user provides a long text or file
- **THEN** the writer skill generates a concise summary
