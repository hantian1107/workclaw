## 新增需求

### 需求: IPC 工作空间操作
系统必须通过 Electron IPC 暴露工作空间操作，以允许前端管理工作空间。

#### 场景: 创建工作空间 IPC
- **当** 使用有效的名称和描述调用 `workspace:create`
- **则** 一个新的工作空间被创建并通过 IPC 响应返回

#### 场景: 列出工作空间 IPC
- **当** 调用 `workspace:list`
- **则** 所有工作空间的列表通过 IPC 响应返回

#### 场景: 切换工作空间 IPC
- **当** 使用有效的工作空间 ID 调用 `workspace:switch`
- **则** 激活的工作空间被更改，并返回成功状态

#### 场景: 添加资源 IPC
- **当** 使用有效的工作空间 ID 和资源详情调用 `workspace:resource:add`
- **则** 资源被添加到工作空间，并返回成功状态
